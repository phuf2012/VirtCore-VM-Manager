# Changelog

## VirtCore 1.0.0 Beta 2

- Replaced the browser dashboard with a local desktop window.
- Added a native installer image picker and VM console launching.
- Added background VM actions, clearer connection feedback, and safer delete prompts.
- Added Tk and `virt-viewer` package dependencies.

## VirtCore 1.0.0 Beta

- First Linux-focused beta release.
- Added a local dashboard backed by QEMU/KVM and libvirt.
- Added VM creation from local installer images and basic power controls.
- Added Debian package and desktop launcher.
